# Supermarket Sales Analysis Dashboard

## 📊 Project Overview
An interactive sales analysis dashboard built using Microsoft Power BI to explore supermarket sales performance, quantity sold, gross income, and customer ratings.

## 🎯 Objectives
- Analyze overall supermarket sales performance.
- Track quantity sold and gross income.
- Compare sales across product lines and cities.
- Explore sales trends over time.
- Enable interactive analysis using slicers.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- CSV Dataset
- Data Visualization

## 📈 Dashboard Features
- KPI cards for key business metrics.
- Sales analysis by product line.
- Sales trend visualization.
- Interactive City and Product Line filters.
- Customer rating and gross income analysis.

## 📁 Project Files
- `Supermarket_Sales_Analysis.pbix` — Power BI project file.
- `supermarket_sales.csv` — Dataset used for analysis.
- `Supermarket_Sales_Analysis.pdf` — Exported dashboard report.

## 🚀 How to Use
1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. If prompted, update the dataset source path to the location of the downloaded CSV file.
4. Explore the dashboard using the available filters.
